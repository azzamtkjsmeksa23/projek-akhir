# projek-akhir
projek akhir membuat aplikasi flowstate dengan python
projek ini berguna untuk membuat kita jika ingin fokus mengerjakan suatu tugas tanpa ingin adanya hambatan dengan distraksi dan gangguan di sekitar kita.

# fitur fitur yang ingin aku hadirkan
  1. mematikan notifikasi
  2. membuat timer untuk lama kita mengerjakan tugas
  3. membuat pengingat selama 10 menit sekali untuk selalu fokus pada tugas
  4. ada tombol berhenti ditengah pengerjaan hanya di pencet jika benar benar tidak bisa mengerjakan atau ada kepentingan saja  
  5. ada tombol ceklis tugas yang sudah selesai
  6. ada fitur menambahkan tugas apa yang ingin dikerjakan 
  7. jika satu saja tugas belum selesai akan ada sanksi
  8. jadi harus ada minimal 1 tugas terselesaikan.
